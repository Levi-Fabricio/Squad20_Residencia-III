# Estrutura do projeto

- `src/components/`: componentes reutilizáveis.
- `src/pages/Login/`: tela de login e seus hooks/serviços/tipos.
- `src/pages/ForgotPassword/`: tela de recuperação de senha.
- `src/pages/Home/`: tela inicial.
- `src/layouts/`: layouts compartilhados das áreas autenticada e pública.
- `src/routes/`: configuração das rotas.
- `src/styles/`: estilos globais, tokens e breakpoints.
- `src/hooks/`: hooks genéricos reutilizáveis.
- `src/utils/`: funções utilitárias.

Os diretórios `components/` e `hooks/` dentro de cada página foram criados para componentes e hooks específicos dessa tela; ficam com `.gitkeep` enquanto não houver arquivos.
